# База новостроек Екатеринбурга → Google Таблица

Скрипт собирает все строящиеся жилые объекты Екатеринбурга из ЕИСЖС (наш.дом.рф)
со сроком ввода до 4 кв. 2028 включительно и обновляет Google Таблицу.
Запуск — одной командой: `python update.py`.

## 1. Установка (один раз)

1. Установите Python 3.10+ (https://www.python.org/downloads/, при установке на Windows
   отметьте «Add Python to PATH»).
2. В папке проекта выполните:
   ```
   pip install -r requirements.txt
   python -m playwright install chromium
   ```

## 2. Подключение Google Таблицы (один раз, ~10 минут)

Скрипт пишет в таблицу от имени «сервисного аккаунта» — это робот-пользователь Google.

**Шаг 1. Проект в Google Cloud**
1. Откройте https://console.cloud.google.com/ и войдите своим Google-аккаунтом.
2. Сверху слева нажмите на выпадающий список проектов → **New Project / Новый проект**.
3. Имя — например `novostroyki`, нажмите **Create / Создать**. Дождитесь уведомления
   и выберите этот проект в том же выпадающем списке.

**Шаг 2. Включить Google Sheets API**
1. Откройте https://console.cloud.google.com/apis/library/sheets.googleapis.com
   (проверьте, что сверху выбран ваш проект).
2. Нажмите **Enable / Включить**.

**Шаг 3. Сервисный аккаунт и JSON-ключ**
1. Откройте https://console.cloud.google.com/iam-admin/serviceaccounts
2. **Create service account / Создать сервисный аккаунт** → имя `sheets-bot` →
   **Create and continue** → роль можно не выбирать → **Done / Готово**.
3. Нажмите на созданный аккаунт → вкладка **Keys / Ключи** → **Add key → Create new key** →
   тип **JSON** → **Create**. Браузер скачает файл `.json`.
4. Переименуйте его в `service_account.json` и положите в папку `config/` проекта.
   Никому не пересылайте этот файл — это пароль робота. В git он не попадёт (`.gitignore`).

**Шаг 4. Таблица и доступ**
1. Создайте пустую Google Таблицу (https://sheets.new).
2. Откройте `config/service_account.json` блокнотом и скопируйте значение `client_email`
   (вида `sheets-bot@novostroyki-123456.iam.gserviceaccount.com`).
3. В таблице нажмите **Настройки доступа / Share**, вставьте этот адрес, роль **Редактор**,
   снимите галочку «Уведомить» → **Отправить**.
4. Скопируйте ID таблицы из адреса: `https://docs.google.com/spreadsheets/d/<ID>/edit`.

**Шаг 5. Файл настроек**
1. Скопируйте `config/.env.example` в `config/.env`.
2. Впишите `SPREADSHEET_ID=<ID>`. Путь к ключу по умолчанию — `config/service_account.json`.

## 3. Первый запуск (по порядку)

```
python discover_api.py        # 1) разведка API: перехват XHR каталога, ответы → raw/discovery/
python update.py --inspect    # 2) реальные поля списка и карточки объекта
python update.py --limit 5    # 3) проверка на 5 объектах, таблица НЕ меняется (raw/ДАТА/preview.csv)
python update.py              # 4) первая полная выгрузка
```

Офлайн-проверка логики без доступа к API: `python -m pytest tests -q`.

**Важно:** наш.дом.рф отдаёт 403 на зарубежные/облачные IP (WAF) — запускайте с российского IP.

Если на шаге 1–2 адреса или имена полей отличаются от ожидаемых:
- адреса API и доп. параметры — в `config/.env` (`NASHDOM_API_LIST`, `NASHDOM_API_OBJECT`,
  `NASHDOM_API_DECLARATION`, `NASHDOM_EXTRA_PARAMS`);
- имена полей — в словаре `FIELDS` в `novostroyki/parse.py`.

При первом запуске лист «Изменения» получает одну строку «первичная загрузка»,
а «Справочник ЖК» заполняется автоматически (все строки с «Проверено вручную = нет»).

## 4. Обновление

- Командой: `python update.py`
- Или в Claude Code напишите: **«обнови таблицу»** (см. `CLAUDE.md`).

В конце печатается отчёт: число объектов и квартир, изменения по типам, сколько новых ЖК
требуют проверки класса, ошибки.

## 5. Что где в таблице

| Лист | Содержимое | Перезаписывается? |
|---|---|---|
| Корпуса | 1 строка = 1 объект ЕИСЖС | да, полностью |
| Справочник ЖК | класс и сайт ЖК | **нет** — только добавляются новые ЖК |
| Изменения | лог: новые, переносы, сдан/выбыл, квартиры, застройщик | **никогда не очищается**, новые сверху |
| Сводка по ЖК, По кварталам, По застройщикам, Требует проверки | формулы, считаются сами | формулы переставляются |
| Методика | источники, фильтры, статистика запуска | да |

- **Класс** в «Корпусах» подтягивается формулой из справочника по названию ЖК — правьте
  класс в справочнике и ставьте «Проверено вручную = да», «Корпуса» обновятся сразу.
- Жёлтым — объекты с переносом срока, зелёным — новые за последнее обновление.
- «Требует проверки = да»: класс пустой / «не определён», ЖК не проверен вручную,
  либо в комментарии есть ⚠ (нет срока, квартир или названия ЖК в ЕИСЖС).

## 6. Сырые данные

`raw/ГГГГ-ММ-ДД/`: страницы списка (`list_page_*.json`), карточки (`cards/`),
снапшот листа «Корпуса» перед перезаписью (`snapshot_korpusa_*.json`), `errors.log`.
Папка `raw/` не коммитится в git.

## 7. Ограничения

- Город фильтруется по тексту адреса ЕИСЖС («Екатеринбург»).
- Район, группа компаний, первоначальный срок — только если они есть в ЕИСЖС; иначе пусто.
  Перенос срока без данных ЕИСЖС определяется по истории листа начиная со второго запуска.
- Класс ищется по открытым страницам erzrf.ru, сайтов ЖК, domclick.ru, cian.ru
  (поиск страниц — через DuckDuckGo). Сайты могут блокировать роботов → «не определён».
- Справочник сопоставляется с корпусами по точному названию ЖК.
