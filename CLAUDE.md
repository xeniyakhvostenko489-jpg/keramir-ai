# Инструкции для Claude Code

## «обнови таблицу» (база новостроек Екатеринбурга)

Когда пользователь пишет «обнови таблицу» (или похожее):
1. Выполни `python update.py` из корня репозитория (полный цикл, ~5–15 минут).
2. Перескажи пользователю итоговый блок «ОТЧЁТ» кратко: объекты, квартиры,
   изменения по типам, новые ЖК для проверки класса, ошибки.
3. При ошибке API наш.дом.рф — запусти `python discover_api.py`, сравни эндпоинты
   с `novostroyki/config.py` и полями `FIELDS` в `novostroyki/parse.py`, предложи правку.

Правила: ничего не придумывать (нет данных — пустая ячейка); существующие строки
листа «Справочник ЖК» не менять; лист «Изменения» не очищать.
Подробности — README.md.
